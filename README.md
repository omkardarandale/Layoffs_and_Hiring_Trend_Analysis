# Layoffs_and_Hiring_Trend_Analysis
Analyzed 60M layoff records and 35M job openings to uncover workforce, hiring, and AI trends. Evaluated 7,000 high-risk companies, identified 11.7M open roles, 50.21% remote jobs, and linked workforce changes with 17.73% revenue growth, 22.78% stock growth, and 6.06% salary budget growth.
